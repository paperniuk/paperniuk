## Selected projects

**[Splash for M1/M2 Macs](https://github.com/paperniuk/splash/releases/tag/1.0.2-m1)**
Port of the Splash LLM inference engine to M1/M2 with custom Metal kernels: Qwen3.8-27B decode about 2x and prefill 2.3-2.7x faster than the stock kernels on an M1 Max, prebuilt one-line install.

**[LM Studio Prism Bonsai](https://github.com/paperniuk/lmstudio-prism-bonsai)**
Makes LM Studio load Ternary Bonsai 2 GGUF models (PQ2_0 / PTQ1_0) through Prism's llama.cpp fork, with a reasoning-effort selector. Linux and Windows, double-click install.

**[oMLX Prism Hadamard](https://github.com/paperniuk/omlx-prism-hadamard)**
Makes oMLX run Prism's Hadamard Qwen3.5 packs (Ternary Bonsai 2, a 27B model in 8.4 GB), plus a guide to adding unrecognised architectures to mlx-vlm.

**[Chat Data Exporter](https://github.com/paperniuk/chat-data-exporter)**
Desktop app for extracting and structuring public contact information from large website collections.

**[Moodle PWA Plugin](https://github.com/paperniuk/moodle-pwa-plugin)**
Enables PWA installation for Moodle while preserving site branding.

**[PrepPilot AI](https://github.com/paperniuk/PrepPilot-AI)**
Mobile app for AI-assisted exam-prep workflows.
